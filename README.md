# 🧠 DataReasoner

> **AI-Powered Intelligent Data Analysis Platform**
>
> DataReasoner is an AI-driven exploratory data analysis (EDA) platform that automatically understands tabular datasets, performs intelligent schema inference, detects data quality issues, applies statistical reasoning, and generates meaningful analytical insights with minimal user intervention.

---

## 🚀 Overview

Traditional EDA tools provide statistics and visualizations, but they require users to manually interpret the data.

**DataReasoner goes beyond traditional EDA** by combining **Machine Learning**, **Statistical Analysis**, and **Large Language Models (LLMs)** to automatically reason about datasets and provide intelligent recommendations.

The system analyzes a dataset from multiple perspectives:

- Semantic understanding of columns
- Automatic schema inference
- Data quality assessment
- Statistical analysis
- Feature importance
- Correlation analysis
- Hypothesis testing
- Information theory
- AI-powered reasoning
- Visualization recommendations

# ✨ Features

## 🤖 Intelligent Schema Inference

Automatically understands dataset semantics using:

- Rule-Based Feature Detection
- Identifier Detection
- Datatype Detection
- Datetime Detection
- Large Language Models (Gemini)

Instead of simply reading column names, the system predicts:

- Semantic Role
- Recommended Datatype
- Column Description
- Feature Importance
- Analytical Usability
